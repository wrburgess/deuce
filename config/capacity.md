# Capacity rationing

The per-cycle budget that [Chapter 0](../sds/00-identity-and-governance.md) → *Foundation-first*
refers to when it says prioritizing also rations effort. The principle is canon; the number — when
there is one — lives here, as adaptive configuration under
[Chapter 1](../sds/01-lifecycle-and-skills.md) → *The adaptive layer's home*.

## Declaration

- **Unrationed today.** No per-cycle budget is declared, and nothing meters AC usage against one.
  Effort is directed the way Chapter 0 already provides: by which issue the HC points the AC at
  next.
- **Revisit when either arrives:** a number from the HC, or Chapter 6's unattended runs — the first
  consumer that would need a budget enforced rather than merely written down.
